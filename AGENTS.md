# Expense Tracker Agent Guide

- Follow [security.md](security.md) for privacy, storage, dependency, and agent security rules.
- Follow [design.md](design.md) for UI, layout, spacing, and component rules.
- Build with Flutter and Isar only.
- Keep architecture simple and feature-based.
- Avoid Riverpod, Bloc, Redux, Firebase, backend work, and unnecessary abstractions.
- Prefer small readable files, practical widgets, and service classes.
- Keep UX polished, responsive, and realistic for solo development.
